# server-resourcepack

Resource pack for _Sabo_1's Minecraft server: textures for the CustomItems plugin.

- `pack.zip` is the file the server sends to players.
- `source/` has the same files unzipped, so textures are easy to edit or replace.

Textures live in `source/assets/sabo/textures/item/`. Animated ones are vertical strips of 32x32 frames with a `.png.mcmeta` file next to them.
